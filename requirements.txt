 Project Overview

The Personal Information Program is a beginner-friendly Python application designed to collect basic details from users and display them in a formatted welcome message.

This project demonstrates the use of user input, variables, and formatted output in Python. It allows users to enter their name, age, hobby, field of study, and area of interest, and then generates a personalized greeting.

The main objective of this project is to help beginners understand how to interact with users through the console and practice fundamental programming concepts in Python.

This project is simple, interactive, and ideal for students who are just starting their programming journey.


1. User Input Section
   - Takes input from the user:
     - name
     - age
     - hobby
     - field of study
     - interest domain

2. Data Storage
   - Stores all inputs in variables:
     - name
     - age
     - hobby
     - fild (field)
     - intrest (interest)

3. Output Section
   - Displays a welcome message using formatted strings (f-strings)
   - Combines all user inputs into a readable sentence

### Code Flow

 📌 Conclusion

The Personal Information Program successfully demonstrates how to interact with users using Python. It collects basic user details and displays them in a structured and
